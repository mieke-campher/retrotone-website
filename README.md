# E-Commerce Website

A university project that showcases a guitar store e-commerce website using PHP and MySQL.

## Features
- User Authentication (Register/Login)
- Shopping Cart System
- Product Listings
- Order Processing
- Responsive UI

## Technologies Used
- PHP: Server-side logic
- MySQL: Database for storing cart, customer, order, products, and users information
- HTML/CSS: Frontend UI Design
- JavaScript: Client-side interactivity (Product image gallery)
- XAMPP: Local development environment
- phpMyAdmin: Database management
